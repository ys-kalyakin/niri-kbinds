# Spec Delta

## MODIFIED Requirements

### Requirement: Карточка «Центр»

Поверх затемнения SHALL отображаться карточка по центру фокусного монитора из двух колонок: слева — поле поиска с автофокусом, сгруппированный список биндов (состав групп и их порядок — как в MVP1 `groups`), строки «title + keycaps», счётчик «N из M биндов» и футер-подсказка `↑↓ выбор · Enter выполнить · Esc закрыть`; справа — шпаргалка важных клавиш (требование «Шпаргалка важных клавиш»). Ширина карточки 900px (не более 92% ширины монитора), радиус 20, тёмный фон, светлая граница, тень.

#### Scenario: Состав карточки на живом конфиге

- **WHEN** запуск на живом конфиге с пустым запросом
- **THEN** карточка из двух колонок: слева поле поиска в фокусе, группы в порядке MVP1, строки с keycaps, счётчик «M из M биндов» (M — общее число биндов, разобранных MVP1-парсером) и футер-подсказка; справа шпаргалка важных клавиш

#### Scenario: Нет важных клавиш — одноколоночная карточка

- **GIVEN** конфиг без единого `hotkey-overlay-title`
- **WHEN** запуск оверлея
- **THEN** правая колонка не отображается, карточка одноколоночная шириной 600px — вид как до появления шпаргалки

## ADDED Requirements

### Requirement: Шпаргалка важных клавиш

Правая колонка карточки SHALL показывать статичную шпаргалку: бинды, у которых в конфиге задан `hotkey-overlay-title` (тот же набор, что показывал штатный PNG-оверлей niri), в виде «title + keycaps» с keycaps из `keys_display`, в порядке конфига. Панель SHALL быть read-only: её содержимое не фильтруется поиском и не реагирует на `↑↓`, `Enter` и клики; если строки не помещаются в карточку, панель SHALL прокручиваться колесом мыши.

#### Scenario: Состав шпаргалки

- **GIVEN** конфиг с 16 биндами, помеченными `hotkey-overlay-title`
- **WHEN** запуск оверлея с пустым запросом
- **THEN** правая колонка показывает ровно эти 16 биндов строками «title + keycaps», кириллические клавиши — символами (например, `Mod+В`)

#### Scenario: Шпаргалка не фильтруется поиском

- **WHEN** ввод запроса сужает левый список до одного бинда
- **THEN** содержимое правой колонки не меняется — в ней по-прежнему все бинды с `hotkey-overlay-title`

#### Scenario: Только просмотр — клики и навигация не действуют

- **WHEN** клик по строке шпаргалки
- **THEN** ничего не происходит: действие не выполняется, оверлей не закрывается, выделение в левом списке не двигается

#### Scenario: Прокрутка длинной шпаргалки

- **GIVEN** биндов с `hotkey-overlay-title` больше, чем вмещает карточка по высоте
- **WHEN** прокрутка колесом мыши над правой колонкой
- **THEN** шпаргалка прокручивается независимо от левого списка
